# RBE 502 - Homework 2

Linearization, equilibria, pole placement, cart-pendulum and Lyapunov/LaSalle analysis.

- `matlab/hw2_p1.m` ... `hw2_p6.m` - one script per problem
- `report/` - write-up (`hw2_solutions.tex`, sections in `sections/`, figures in `figures/`)

Needs MATLAB with the Symbolic Math and Control System toolboxes.
Run each script from the `matlab/` folder. `hw2_p5.m` and `hw2_p6.m` also write their plots into `report/figures/`.

Build the report: `cd report && pdflatex hw2_solutions.tex` (run twice).
